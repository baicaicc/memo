# memo ROADMAP

> 只管方向，不记状态。状态看 GitHub Issues。

## 近期（纯前端打磨）

- V2 玩法：N-back 硬核模式（视觉单通道）、配对联想（物品归位）。
- 音效（howler.js + audio sprite）与动效润色。
- 设备体验验证：Agent 用 Android 模拟器过一遍核心链路即算通过；真实手机（含微信内 iOS）就是用户日常使用，有问题再开新迭代。

## 中期（数据与服务端）

- 云端存档：成绩与答题明细随档案上传，恢复码找回、跨设备合并（MEMO-6）。
- 历史曲线、答题明细的进一步利用（为 AI 教练准备数据）。
- 用户标识：恢复码；需要社交或免记码时再考虑微信授权，绑定到同一份档案。
- 选型原则：能 Serverless 不自建；域名与备案已就绪（sesamebox.cn，腾讯云）。

## 远期（AI 教练）

- 接入 DeepSeek 类模型做非实时分析：定期总结记忆表现、给出训练建议、针对弱项出题方向、辅助难度曲线调参。
- AI 只做建议与总结，不进实时游玩链路（不追求低延迟）。
